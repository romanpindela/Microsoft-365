# Microsoft Teams PowerShell Automation Modules

[![PowerShell](https://img.shields.io/badge/PowerShell-5.1%20%7C%207%2B-blue.svg)](https://microsoft.com/powershell)
[![Platform](https://img.shields.io/badge/Platform-Microsoft%20Teams-464EB8.svg)](https://www.microsoft.com/microsoft-teams)
[![Microsoft Graph](https://img.shields.io/badge/Microsoft%20Graph-v1.0-008272.svg)](https://learn.microsoft.com/graph/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Enterprise-grade PowerShell automation utilities and governance scripts for **Microsoft 365** and **Microsoft Teams** lifecycle management, tenant-wide permission auditing, cache troubleshooting, and client identity remediation.

---

## 🛠️ Tool Catalog & Index

| Script / Tool | Description | Version |
| :---- | :---- | :---- |
| [Get-TeamsAndUsers](./Get-TeamsAndUsers) | Audits Microsoft Teams and underlying SharePoint sites, mapping users, owners, members, and guest permissions in clean tabular view. | 1.0.0 |
| [Reset-TeamsIdentityCache](./Reset-TeamsIdentityCache) | Comprehensive remediation tool for Microsoft Teams authentication loops, token expiration, stale tenant profiles, and WAM/IdentityCache corruption. | 1.0.0 |
